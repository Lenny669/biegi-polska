# Biegi w Polsce — kalendarz od 5 km do ultra

Statyczna strona (GitHub Pages) z kalendarzem imprez biegowych w Polsce: filtry po dystansie, terenie, województwie, miesiącu i seriach (Korona Maratonów Polskich, Korona Półmaratonów Polskich, Złota Seria 42 i in.), linki do zapisów oraz progi cenowe z terminami.

- `index.html` — strona (bez zależności, czysty HTML/CSS/JS)
- `races.json` — dane; aktualizowane automatycznie co noc około północy

Ceny i terminy pochodzą ze stron organizatorów. Przed zapisem zawsze sprawdź szczegóły na oficjalnej stronie biegu.
